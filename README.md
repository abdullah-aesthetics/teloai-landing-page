# TeloAI Landing Page

A responsive landing page built with HTML and CSS only. It recreates the first three sections of a provided Figma design for TeloAI, an AI WhatsApp agent for UK dental practices.

## Purpose

This project was built to practise converting a design reference into code. The goal is to match the layout, spacing, typography and colours of the design on both desktop and mobile.

## Sections

1. **Hero:** navigation bar, headline, intro text, call-to-action buttons and a phone chat mockup
2. **The Problem:** three cards explaining why practices lose leads
3. **The Solution:** five cards showing how TeloAI helps

## Technologies Used

- HTML5
- CSS3 (Flexbox, CSS Grid, custom properties, media queries)
- Google Fonts (Poppins and Caveat)
- Inline SVG icons

No JavaScript, frameworks or templates are used.

## How to Run the Project

1. Download or clone this repository:
   ```
   git clone https://github.com/abdullah-aesthetics/teloai-landing-page.git
   ```
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.

An internet connection is needed so the Google Fonts can load.

## Responsive Design

- Desktop layout: screens 1024px wide and above
- Mobile layout: screens below 1024px

Sizes use one scaling unit, so the page keeps the proportions of the original design as the screen width changes.
